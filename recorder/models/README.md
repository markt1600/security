# YuNet local face detector

Official OpenCV Zoo model `face_detection_yunet_2026may.onnx`, stored as `yunet.onnx`.

- Source: https://github.com/opencv/opencv_zoo/tree/47534e27c9851bb1128ccc0102f1145e27f23f98/models/face_detection_yunet
- SHA-256: `ebafce4e3c118d6554634be5c27ab333b4c047a9a8c3faf1d7cf93101c22f0f0`
- License: MIT, reproduced in `LICENSE`.
- Runs with the installed OpenCV 5.0 CPU inference engine. No runtime downloads or cloud inference.

Only face detection is used. There is no recognition model, face embedding database, naming, or comparison against known people.
